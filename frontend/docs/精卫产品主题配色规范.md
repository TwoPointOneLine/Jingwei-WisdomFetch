# 精卫产品主题配色规范

> **项目**：精卫 · 金融智能知识库（Jingwei WisdomFetch）
> **版本**：v1.0
> **适用范围**：精卫 Web 端 / 移动端 / 管理后台全产品界面
> **设计取向**：权威正式 · 金融感（与方案 B · 盾意栖知 Logo 视觉同源）

---

## 一、概述与核心原则

本规范定义精卫产品界面的统一主题配色，作为设计、前端开发、品牌物料的共同基准。

### 核心原则

1. **以 Logo 品牌色为锚点自然延伸**：Logo 已定下深海靛 / 沉稳金 / 知青绿 / 云白四色，界面配色在此基础上派生，避免品牌感断裂。
2. **权威正式、金融感突出**：整体倾向沉稳深邃，契合银行 / 券商级金融知识库的合规定位。
3. **"稳"字当头**：以大面积中性色为底，品牌主色克制使用，点缀 / 功能色仅占约 10%，不花哨、不压抑。
4. **合规语义清晰**：功能语义色独立定义，风险提示用橙色规避"亏损 / 暴跌"联想。
5. **暗色可映射**：所有颜色均给出暗色模式对应值，保证深浅主题视觉一致。

## 六、使用比例（60-30-10 法则）

| 占比 | 颜色类型 | 具体色 | 应用区域 |
| :--- | :--- | :--- | :--- |
| 60% | 中性色（背景 + 文字） | 白 / 浅灰 / 深灰 | 页面底色、卡片、正文 |
| 30% | 品牌主色 | 深海靛 | 导航栏、标题、关键按钮 |
| 10% | 点缀 / 功能色 | 沉稳金 + 知青绿 + 语义色 | 标签、图标、状态提示 |

> 该比例保证界面不花哨、不压抑，符合金融产品"稳"的定位。

## 九、避坑指南

| ❌ 不要用 | ✅ 改用 | 原因 |
| :--- | :--- | :--- |
| 纯黑 `#000000` 做正文 | 深灰 `#3A3F4B` | 纯黑在大屏上刺眼，深灰更舒适 |
| 亮橙 / 正红做主色 | 沉稳金 `#C89B3C` | 避免"亏损 / 激进"联想 |
| 渐变色大面积铺底 | 纯色 / 微渐变 | 金融产品要稳，大面积渐变易显廉价 |
| 荧光绿做成功态 | 知青绿 `#2ECC71` | 荧光色不正式 |
| 纯白 `#FFFFFF` 做页面底 | 浅灰 `#F5F7FA` | 纯白底 + 白卡片无层次感 |

## 十、项目定位与合规提示

精卫（Jingwei WisdomFetch）是面向普通用户的智能金融知识库系统，定位为金融知识查询与资料理解工具，**不提供个性化投资建议、不承诺收益、不替代正式产品文件或监管文件**。本配色规范以深海靛为主色传递专业信任，以知青绿标记合规 / 可信来源，以橙色提示风险，从视觉层面服务于"权威、可追溯、不编造"的产品定位。

> **Slogan**：衔海求知，汇流成库 —— 每一问，都有来处。
