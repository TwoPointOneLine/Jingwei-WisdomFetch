## 一、文档说明

本文档基于《金融知识库项目需求说明》与《精卫品牌体系方案》，进一步明确产品的**英文命名体系**与 **Logo 视觉概念**，为 UI 设计、产品包装、市场推广及国际化学术/技术交流提供统一的品牌依据。

品牌核心叙事不变：**精卫衔海求知，汇流成库；每一问，都有来处。**

## 二、项目中文名称回顾

| 项目 | 内容 |
| :--- | :--- |
| **中文名称** | 精卫 |
| **命名由来** | 取自"精卫填海"神话。精卫鸟衔西山木石以填沧海，寓意系统从浩如烟海的金融文档（PDF / 公告 / 研报 / 产品说明书）中，日复一日为用户**衔取**最相关的知识碎片，筑成可理解的知识陆地。 |
| **品牌隐喻** | 沧海 = 海量金融文档；衔石 = 精准检索与知识提取；填海成库 = 把晦涩条款转化为可读答案。 |
| **合规契合度** | 名字中性、不暗示涨跌，天然契合"知识查询工具、不荐股、不承诺收益"的合规定位。 |

## 三、英文名称方案

精卫的英文命名需兼顾**神话识别度**、**金融专业感**与**产品功能暗示**。以下按四种取向给出候选，并最终给出推荐组合。

### 3.1 音译派（保留文化基因，适合打造国际品牌）

| 英文名 | 说明 | 评价 |
| :--- | :--- | :--- |
| **Jingwei** | 最简洁，发音 Jing-way，易记。遵循 Huawei、Tencent 的命名逻辑。 | 推荐作主品牌 |
| **Jingwei KB** | 全称 Jingwei Knowledge Base，KB 直接点明产品形态。 | 适合技术文档 |
| **Jingwei Finance** | 强调金融领域。 | 略宽泛 |

### 3.2 意译派（功能直译，降低理解门槛）

| 英文名 | 说明 | 评价 |
| :--- | :--- | :--- |
| **WisdomFetch** | Wisdom（智慧）+ Fetch（衔取 / 检索），完美对应"精卫衔石"的动作与知识库定位。 | **强烈推荐作产品英文名** |
| **KnowVault** | Knowledge + Vault（金库），强调安全存储与知识沉淀。 | 备选 |
| **InfoReclaim** | Information + Reclaim（开垦 / 填海），呼应"精卫填海"从信息海洋中开垦出知识陆地。 | 意象贴切 |
| **SeaOfKnow** | Sea of Knowledge，诗意但稍长。 | 可作 Slogan 素材 |

### 3.3 意象派（抽象隐喻，科技感强）

| 英文名 | 说明 | 评价 |
| :--- | :--- | :--- |
| **QuillWise** | Quill（羽毛笔 / 鸟的羽毛，代表知识与书写）+ Wise（智慧），金融文档、知识、鸟羽三重意象合一。 | 有记忆点 |
| **BeakLink** | Beak（鸟喙）+ Link（连接），强调系统连接用户与晦涩文档的桥梁作用。 | 功能指向清晰 |
| **PebbleCarry** | Pebble（碎石，精卫衔的石子）+ Carry，直译神话动作。 | 独特但偏长 |

### 3.4 最终推荐组合

| 项目 | 推荐内容 |
| :--- | :--- |
| **主品牌名** | `Jingwei` |
| **产品英文名** | `Jingwei WisdomFetch` |
| **英文 Slogan** | *"Fetching knowledge from the sea of finance."* |
| **品牌缩写** | `JWF` |

> **推荐理由**：`Jingwei` 保留文化基因与国际辨识度；`WisdomFetch` 用"Fetch（衔取 / 检索）"一词把神话动作、产品功能（知识检索）与价值主张（智慧传递）三者合一，既是名字也是产品能力的自描述。

## 四、Logo 设计理念

### 4.1 核心图形概念：衔叶之鸟 × 问号负空间

Logo 以"精卫衔叶"为核心图形，将神话意象、产品功能与金融属性三重融合。

| 设计元素 | 图形处理 | 寓意 |
| :--- | :--- | :--- |
| **精卫鸟侧影** | 喙部微张、体态小巧、姿态向上飞翔 | 象征主动探索与勤奋检索 |
| **喙衔一片叶子** | 叶子抽象为文档 / 纸张的变形 | 代表从海量资料中衔取的知识碎片 |
| **鸟身负空间构成"？"** | 腹部轮廓或翅膀线条巧妙形成问号 | 直接关联"问答"产品功能 |
| **海浪基底线条** | 底部三条极简波浪线 | 代表"沧海"，也象征数据流动 |

### 4.2 品牌色卡

| 颜色名 | 色值（HEX） | RGB | 用途 | 寓意 |
| :--- | :--- | :--- | :--- | :--- |
| **深海靛** | `#1B2A4E` | 27 / 42 / 78 | 主图形 / Logo 主体色 | 专业、深邃、金融信任感 |
| **知青绿** | `#2ECC71` | 46 / 204 / 113 | 叶子 / 文档点缀色 | 知识生长、合规安全、希望 |
| **暖金** | `#F5A623` | 245 / 166 / 35 | 鸟喙 / 问号高亮色 | 金融属性、阳光、价值 |
| **云白** | `#FFFFFF` | 255 / 255 / 255 | 背景 / 文字 | 清晰、透明、无编造 |

> 印刷场景如需 CMYK 值，可在此基础上由设计师按输出标准转换；本文档以 HEX / RGB 为主，覆盖屏幕与数字化场景。

### 4.3 字体搭配

| 文字 | 推荐字体 | 字重 / 样式 | 说明 |
| :--- | :--- | :--- | :--- |
| 中文"精卫" | 思源黑体（Source Han Sans）| Light / 字间距宽松 | 体现轻盈感，避免厚重 |
| 中文副标题 | 书法行书（可选）| 一笔勾勒鸟形 | 增强品牌个性，仅用于品牌主视觉 |
| 英文 `Jingwei` | Inter / Helvetica Neue | Medium | 现代无衬线，清晰稳重 |
| 英文 `WisdomFetch` | Inter / Helvetica Neue | Italic（斜体）| 斜体暗示"衔取"的动态 |

### SVG 代码说明

| 代码段落 | 对应设计元素 |
| :--- | :--- |
| `rect`（背景）| 白色圆角背景底板 |
| 两条 `path`（海浪）| 底部极简海浪线条，代表沧海与数据流动 |
| 主体 `path`（鸟身体）| 精卫鸟侧影轮廓，同时构成问号负空间 |
| `line`（鸟喙）+ `path`（叶子）| 暖金色喙衔住知青绿色叶子 / 文档 |
| `circle`（圆点）| 鸟眼位置圆点，同时作为问号圆点 |
| 翅膀 `path` | 补充鸟的形态辨识度 |
| 两个 `text` | 中文"精卫"+ 英文 "WisdomFetch" 品牌字 |
