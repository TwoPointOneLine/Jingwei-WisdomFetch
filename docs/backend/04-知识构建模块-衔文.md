# 知识构建模块 · 衔文（jingwei_knowledge）

> 对应架构模块：衔文（知识构建）/ FR-IMP-*
> 代码：`backend/services/knowledge/src/jingwei_knowledge/`，入口 `api.import_server.main:app`，端口 8081

## 1. 职责

将金融文档（PDF / Word / Markdown 等）加工为可检索的知识切片并写入向量库：

- 文件接收与落盘（MinIO 对象存储）；
- 解析（PDF→Markdown，含图片抽取）；
- 智能切分；
- 统一元数据标注（含产品/事项名称识别）；
- BGE-M3 向量化；
- 写入 Milvus 向量库；
- 任务进度可视化（节点级状态）。

## 2. 接口（main.py）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/upload` | 多文件批量上传；每个文件生成 `task_id`，写入 `date_based_root_dir/{task_id}`，后台触发导入链 |
| GET | `/status/{task_id}` | 查询任务状态：整体状态 + 已完成/进行中节点（`get_task_status` / `get_done_task_list` / `get_running_task_list`） |
| GET | `/health` | 健康检查 |

> 前端经网关 `/api/knowledge/*` 与 `/api/import/*` 两前缀访问（兼容旧路由）。

## 3. 导入链（LangGraph StateGraph）

编排代码：`process/import_chain/main_graph.py`。节点（`process/import_chain/nodes/`）均为 `StateGraph` 节点，统一用 `@node_log("node_xxx")` 记录步骤日志，并通过 `jingwei_common.web.task_utils` 上报节点级进度。

```
node_entry
   └─(PDF ? node_pdf_to_md : node_md_img)
          └─ node_md_img
                 └─ node_document_split
                        └─ node_item_name_recognition
                               └─ node_bge_embedding
                                      └─ node_import_milvus → END
```

| 节点 | 职责 | 对应 FR-IMP |
|---|---|---|
| `node_entry` | 入口：参数校验、初始化状态、标记任务运行 | 接收/校验 |
| `node_pdf_to_md` | PDF 解析为 Markdown（MinerU），抽取图片 | FR-IMP-002 解析 |
| `node_md_img` | Markdown 图片处理与归档 | FR-IMP-002 解析 |
| `node_document_split` | 智能切分（按语义/长度，重叠窗口） | FR-IMP-003 切分 |
| `node_item_name_recognition` | 识别产品/事项名称，写入统一元数据 | FR-IMP-004 元数据 |
| `node_bge_embedding` | BGE-M3 本地向量化（`jingwei_common.ai.embedding`） | FR-IMP-005 向量化 |
| `node_import_milvus` | 切片+向量写入 Milvus（`jingwei_common.clients.milvus_client`） | FR-IMP-006 入库 |

## 4. 基础设施依赖

- **对象存储**：原始文件与解析产物落 MinIO（`jingwei_common.clients.minio_client`，默认桶 `jingwei`）。
- **向量库**：Milvus（`MilvusClientWrapper.insert` 写入；集合/字段由 `milvus_config` 定义）。
- **任务状态**：节点进度存 MongoDB（`jingwei_common.web.task_utils`）。
- **模型**：向量化用本地 BGE-M3（`jingwei_common.ai.embedding` / `embedding_config`），离线部署。
