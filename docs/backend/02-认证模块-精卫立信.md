# 认证模块 · 精卫立信（jingwei_auth）

> 对应架构模块：精卫立信（认证）/ FR-AUTH-*
> 代码：`backend/services/auth/src/jingwei_auth/`，入口 `api.auth_server.main:app`，端口 8083

## 1. 职责

- 用户注册、登录、登出；
- 签发与校验 JWT（`jingwei_common.auth`）；
- 角色分配与查询（admin / member / guest）；
- 注册时同步在 `user_profiles` 初始化用户档案。

## 2. 接口（main.py）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/auth/register` | 注册；默认角色 `member`，命中 `AUTH_BOOTSTRAP_ADMIN`（逗号分隔）的用户为 `admin` |
| POST | `/auth/login` | 校验密码后签发 token |
| GET | `/auth/me` | 凭 token 返回 `username` 与 `role` |
| POST | `/auth/logout` | 登出（无状态 token 由前端丢弃；服务端记录撤销可选） |
| GET | `/health` | 健康检查 |

## 3. 角色模型（constants.py）

- `ROLE_ADMIN = "*"`：全权限，可管理用户与角色；
- `ROLE_MEMBER`：注册默认角色，可使用知识库与问答；
- `ROLE_GUEST`：未登录访客，仅可发起匿名会话（前端 `anon_id` 隔离）。

## 4. 关键实现（auth_service.py）

- `register(username, password)`：密码加密存储，调用 `user_profiles` 初始化档案，角色由 `_default_role()` 决定（环境变量 `AUTH_BOOTSTRAP_ADMIN` 优先）。
- `verify_password(username, password)`：校验凭据。
- `issue_token(username)`：调用 `jingwei_common.auth` 签发 JWT。
- 角色查询复用 `jingwei_common.auth.get_user_role`。

## 5. 与用户模块关系

认证服务负责"身份与凭证"，用户服务（精卫明册）负责"档案与角色管理"。注册时两服务通过共享 `user_profiles` 集合（`jingwei_common.constants.COLLECTION_USER_PROFILES`）保持一致性；权限边界（修改本人/他人档案、设角色限 admin）在用户服务实现。

## 6. 对应功能编号

| 架构功能（FR-AUTH-*） | 后端实现 |
|---|---|
| 注册 / 登录 / 登出 | `main.py` 三个端点 + `auth_service` |
| Token 签发与校验 | `jingwei_common.auth` |
| 角色分配（admin/member） | `_default_role()` + `AUTH_BOOTSTRAP_ADMIN` |
| 权限模型 | `constants.ROLE_*` |
