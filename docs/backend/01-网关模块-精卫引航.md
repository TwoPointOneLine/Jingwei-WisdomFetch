# 网关模块 · 精卫引航（jingwei_gateway）

> 对应架构模块：精卫引航（网关）/ FR 路由与统一入口
> 代码：`backend/services/gateway/src/jingwei_gateway/`，入口 `api.gateway_server.main:app`，端口 8080

## 1. 职责

网关是系统唯一对外入口，负责：

- 路由转发：按前缀把 `/api/*` 请求转发到对应后端服务；
- 统一鉴权前置：校验 `Authorization: Bearer <token>`（strict / optional 两档）；
- SSE 透传：把问答流式接口转发给 query 服务并原样回传；
- 静态托管：挂载 `frontend/dist`，为前端提供 SPA 入口；
- 健康检查：暴露 `/health` 与路由表。

## 2. 路由表

定义在 `api.gateway_server/config.py`，前缀 → 后端服务（host 由 `GATEWAY_*_HOST` 覆盖，默认 `127.0.0.1`）：

| 网关前缀 | 转发目标 | 服务 |
|---|---|---|
| `/api/auth/*` | `GATEWAY_AUTH_HOST:8083` | 认证 |
| `/api/user/*` | `GATEWAY_USER_HOST:8084` | 用户 |
| `/api/knowledge/*`、`/api/import/*` | `GATEWAY_IMPORT_HOST:8081` | 知识构建（两前缀兼容前端旧路由） |
| `/api/query/*` | `GATEWAY_QUERY_HOST:8082` | 问答 |

转发逻辑：`proxy.py` 取最长前缀匹配，`forward()` 剥离前缀后拼接目标 URL。

## 3. 鉴权前置（middleware.py）

- 模式 `GATEWAY_AUTH_MODE`：`strict`（白名单外必须有效 token，否则 401）/ `optional`（默认，带 token 则校验，未带放行为 guest）。
- 白名单 `PUBLIC_PATHS`：`/api/auth/*`（注册/登录/登出由认证服务自身校验）、`/api/query/models`（模型列表公开）。
- **SSE 免鉴权**：`SSE_PREFIX=/api/query/chat/stream`（EventSource 不能带 header），支持 `?token=` 兜底解析（`_resolve_token`）。
- Token 校验复用 `jingwei_common.auth.AuthClient.validate_token`（本地校验，免跨服务 HTTP）。

## 4. 静态托管与 SPA

- `_find_dist()` 优先读 `GATEWAY_DIST_DIR`，否则回退到 `<backend 父目录>/frontend/dist`。
- 存在时挂载 `/assets` 并兜底 `/` 返回 `index.html`，使前端路由刷新可用。

## 5. 对应功能编号

| 架构功能 | 后端实现 |
|---|---|
| 统一 API 网关 / 路由转发 | `proxy.py` + `config.py` |
| 统一鉴权前置 | `middleware.py` |
| SSE 透传 | `forward()` 透传 `StreamingResponse` |
| 前端托管 | `main.py` 静态挂载 |

> 注：会话归属、guest/登录隔离在问答服务实现（见 `05-问答模块.md`），网关仅做传输层鉴权。
