# 用户模块 · 精卫明册（jingwei_user）

> 对应架构模块：精卫明册（用户）/ 档案与角色管理
> 代码：`backend/services/user/src/jingwei_user/`，入口 `api.user_server.main:app`，端口 8084

## 1. 职责

- 用户档案（user_profiles）的创建、查询、修改；
- 角色管理：查询角色清单、由 admin 设置用户角色；
- 权限边界：档案修改限本人或 admin；设角色仅 admin。

## 2. 接口（main.py）

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| POST | `/user/profile` | 本人 / admin | 创建档案；普通用户仅可为本人建档，admin 可指定 `role` |
| GET | `/user/profile/{username}` | 任意登录用户 | 查询档案 |
| PUT | `/user/profile/{username}` | 本人 / admin | 修改档案（`ForbiddenError` 403 越权） |
| GET | `/user/roles` | 登录用户 | 角色清单（admin/member/guest 及中文名） |
| POST | `/user/{username}/role` | **仅 admin** | 设置角色（`require_role({ROLE_ADMIN})`） |
| GET | `/user/{username}/permissions` | 登录用户 | 查询用户权限 |
| GET | `/health` | 公开 | 健康检查 |

## 3. 角色与权限边界

- 角色常量：`jingwei_common.constants.ROLE_ADMIN / ROLE_MEMBER / ROLE_GUEST`。
- 档案写权限：非 admin 修改他人档案 → `ForbiddenError`（HTTP 403）。
- 角色赋值：仅 admin（`assign_role` 内 `auth_client.require_role({ROLE_ADMIN})`）。
- 鉴权复用 `jingwei_common.auth.AuthClient`（本地校验 token / 角色，免 HTTP）。

## 4. 数据访问（user_service.py）

- `get_profile(username)` / `get_or_create_profile(username)` / `update_profile(username, data)` / `set_role(username, role)`。
- 持久化集合：`jingwei_common.constants.COLLECTION_USER_PROFILES`（与认证服务共享，注册即初始化）。

## 5. 对应功能编号

| 架构功能 | 后端实现 |
|---|---|
| 用户档案管理 | `/user/profile*` 端点 + `user_service` |
| 角色管理 | `/user/{username}/role` + `set_role` |
| 权限边界控制 | `ForbiddenError` / `require_role` |
| 多角色（admin/member/guest） | `constants.ROLE_*`（与认证一致） |
